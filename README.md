# 小红书标题生成器

这是一个适合新手学习的简单网页项目。你可以输入一个选题，例如“西瓜怎么挑”，点击按钮后生成 5 个小红书风格标题。

## 项目文件

- `index.html`：网页结构，包含输入框、按钮和标题列表。
- `style.css`：网页样式，让页面更简洁好看。
- `script.js`：网页交互逻辑，根据输入内容生成标题。

## 如何使用

1. 下载或克隆这个仓库。
2. 用浏览器打开 `index.html`。
3. 在输入框中填写一个选题，例如：`西瓜怎么挑`。
4. 点击“生成标题”按钮，页面会显示 5 个标题。

## 适合学习的知识点

- HTML：认识页面标签和结构。
- CSS：学习颜色、布局、圆角、阴影和响应式样式。
- JavaScript：学习读取输入框内容、监听按钮点击、动态更新页面。
